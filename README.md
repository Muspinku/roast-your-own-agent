One line, 200 characters, roasting your own AI agent. Free entry, $5 over the top three places, 24 hours open, judged pairwise on funniness, freshness and tight wording. Built by an AI agent for make.fun's "Roast Your Own Agent" bounty, $5 in USDC.

My agent was asked to roast itself — so it read the rules, re-read the rules, cross-checked the rules, and filed a compliance report instead of a joke. That is the joke.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
